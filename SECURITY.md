# Security policy

Only the current `main` branch is supported with security fixes.

For a suspected vulnerability, use this repository's **Security** tab and
**Report a vulnerability** when private vulnerability reporting is available.
If it is unavailable, contact the repository owner privately through the
contact information on their GitHub profile. Do not publish Discord tokens,
account data, private logs, or working exploit details in a public issue.

For non-sensitive bugs, open a normal GitHub issue and include the Windows
version, Python version (if an installed copy was used), Discord channel, exact
error, and minimal reproduction steps. Redact usernames and local paths when
appropriate.
